Case Study: Fairalyze AI

Building an accessible auditing dashboard to uncover demographic and gender bias in predictive machine learning models.

Role UI/UX Designer & Front-End
Timeline GNEC Hackathon (48 Hours)
Focus Area UN SDGs 5 (Gender) & 10 (Inequality)
🎯

01. The Challenge

Artificial intelligence models increasingly influence sensitive decisions in recruitment, lending, and content moderation. However, when trained on historical datasets, these models frequently amplify latent societal biases against underrepresented groups.

The Problem: Non-technical stakeholders and small engineering teams lack accessible, lightweight tooling to quickly audit predictive models for disparate impact and representation parity.

🛠️

02. Role & Rapid Prototyping

As part of our hackathon team, I spearheaded the UI/UX design architecture in Figma and translated the interfaces into clean front-end code while collaborating closely on integrating bias detection logic.

Given the tight 48-hour timeline, we prioritized a user-centric dashboard that distills complex statistical variance into intuitive visual risk gauges and clear metric breakdowns.

✨

03. Key Features & Solutions

Disparate Impact Gauge

Visual 0–100% fairness score calculated across sensitive demographic attributes.

Demographic Parity Visualizer

Interactive chart comparing model acceptance rates across gender and racial groups.

Actionable Recommendations

Plain-language mitigation tips for data balancing and threshold calibration.

🏆

04. Outcome & Key Takeaways

Fairalyze AI was successfully demonstrated to the GNEC Hackathon jury, earning praise for making abstract ethical AI principles concrete through thoughtful interface design.

✦ Mastered rapid high-fidelity prototyping under tight hackathon deadlines
✦ Learned how to simplify complex mathematical data visualizations for general users
✦ Strengthened cross-functional collaboration between frontend and algorithmic pipelines

Case Study: Responsive Calculator Application

Architecting a clean mathematical parser, floating-point precision handler, and responsive tactile interface.

Role Full Design & Development
Type Independent Project
Tech HTML5, CSS3, Vanilla JS
🎯

01. The Objective

The goal was to build a rock-solid calculation engine without relying on external libraries or the vulnerable `eval()` function, ensuring error tolerance for chained operations, zero-division, and decimal precision.

🎨

02. Interface & Tactility

Designed with clean ergonomics: high-contrast operation keys, distinct functional action clusters (AC, sign toggle, percentage), subtle push animations on press, and full keyboard event listener support for seamless desktop typing.

⚡

03. Engineering & Key Architecture

State Machine Parser

Maintains `previousOperand`, `currentOperand`, and `operation` state cleanly across multiple chained sequences.

Precision Formatting

Handles JavaScript floating-point idiosyncrasies (e.g. 0.1 + 0.2) and formats large numbers with dynamic localization commas.

Keyboard & Touch Ready

Fully responsive CSS Grid layout that scales naturally from 320px mobile screens up to desktop 4K displays.

💡

04. Outcome & Key Learnings

This project honed fundamental DOM manipulation and event delegation skills, edge-case debugging, and taught the value of modular, decoupled state management in vanilla front-end development.
